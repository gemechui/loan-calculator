# Loan Calculator - installable web app (Android and iPhone)

Publish these files on GitHub Pages (free). Afterwards anyone can open the link and add the calculator to the home screen.

## Publish (one time, about 10 minutes)
1. Sign in at github.com. Click "+" > "New repository". Name: `loan-calculator`. Choose Public. Create.
2. Click "uploading an existing file". Unzip this folder and drag ALL files and the `icons` folder into the page. Commit.
3. Repository > Settings > Pages. Under "Build and deployment" choose Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`. Save.
4. Wait 1-2 minutes. The page shows your link: https://YOUR-USERNAME.github.io/loan-calculator/

## Install on a phone
- iPhone (Safari): open the link > Share button > "Add to Home Screen" > Add.
- Android (Chrome): open the link > menu (three dots) > "Install app" or "Add to Home screen".
The app opens full screen with its own icon, and works offline after the first open.

## Update later
Replace `index.html` in the repository and commit. Phones receive the new version the next time they open the app online.
